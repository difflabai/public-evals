# Instrument changes: eval 2 (coupled portfolio) and the shared coupled instrument

What the release package (`dbwm/eval2`) does differently from the private harness that ran the paper's eval-2
sessions. File:line references point into that harness's frozen snapshot (`scripts/bwm_coupled/...`, base
commit 87a3ffac). Ledger ids (E23-Dn, Nnn, Annx) refer to the research ledger; "Appendix A" is the paper's
correction ledger. Cross-cutting runtime changes (sandbox, `--tools`/`--restricted`, env allowlist, oracle server,
turn budget, outcomes, attempts, interleave) are described in the core rows; eval-2 rows only point at them.

Classes: **(a)** integrity defect fixed in v1; **(b)** stale or wrong documentation corrected; **(c)** documented
limitation that cannot be fixed after the fact; **(d)** port mechanics (no behavioural change intended).
