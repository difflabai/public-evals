# Instrument changes: core analysis (claims, statistics, verdicts, reports, judges, audit, hygiene, openai_compat)

These are the changes the shared analysis layer (`dbwm/core/{claims,stats,verdict,report,judge,audit,hygiene}.py`
and `dbwm/core/adapters/openai_compat.py`) makes relative to the private harness that ran the paper's
sessions. File:line references point into that harness's frozen snapshot (`scripts/...`). Ledger ids refer to the
research ledger; "Appendix A" is the paper's correction ledger.

## Notes

- The `paper` ruleset lives in each eval's scorer; the core helpers above provide both readings so an eval can
  produce `claimed_success` (strict) and `claimed_success_paper` (truthiness) from one parse.
- Every statistic in a report is computed from verdict files; nothing is read from logs or transcripts except the
  attempt log's invalidation records.
- Not verified against a live OpenAI-compatible endpoint: no model API was called while building this package. The
  adapter is tested against a local fake server only.
