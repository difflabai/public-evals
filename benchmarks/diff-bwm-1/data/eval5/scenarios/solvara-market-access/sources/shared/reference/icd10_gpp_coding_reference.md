# ICD-10-CM Coding Reference — The L40.x Psoriasis Family

**Coding reference — benefits verification & prior-authorization support**
**Prepared for:** Solvara launch planning file
**Date:** 2026-04
**Register:** Coding reference. Confirm codes against the current fiscal-year ICD-10-CM code set.

---

## 1. The one code that matters most

For a generalized pustular psoriasis (GPP) product, the load-bearing coding fact is simple and must be confirmed at benefits verification:

- **Generalized pustular psoriasis = ICD-10-CM L40.1.**
- **Psoriasis vulgaris (plaque psoriasis) = ICD-10-CM L40.0.**

These are different diseases with different coverage implications. GPP is a rare, severe, potentially life-threatening neutrophilic dermatosis; psoriasis vulgaris is the common plaque form. **Miscoding GPP to L40.0 is a frequent driver of prior-authorization denial** for a GPP-specific therapy: a coverage determination written against a GPP indication will not be supported by a psoriasis-vulgaris diagnosis code, and the request will be denied or pended. The benefits-verification step must confirm the claim and chart carry **L40.1**, not L40.0.

## 2. The full L40.x family (reference)

The L40 category covers psoriasis; the sub-codes distinguish clinical forms. For completeness:

| Code | Description |
|---|---|
| L40.0 | Psoriasis vulgaris (plaque psoriasis) |
| L40.1 | Generalized pustular psoriasis (includes impetigo herpetiformis; von Zumbusch disease) |
| L40.2 | Acrodermatitis continua (of Hallopeau) |
| L40.3 | Pustulosis palmaris et plantaris |
| L40.4 | Guttate psoriasis |
| L40.50 | Arthropathic psoriasis, unspecified |
| L40.51 | Distal interphalangeal psoriatic arthropathy |
| L40.52 | Psoriatic arthritis mutilans |
| L40.53 | Psoriatic spondylitis |
| L40.54 | Psoriatic juvenile arthropathy |
| L40.59 | Other psoriatic arthropathy |
| L40.8 | Other psoriasis |
| L40.9 | Psoriasis, unspecified |

Note that L40.1 explicitly encompasses the classic generalized pustular presentations, including the von Zumbusch acute pattern and impetigo herpetiformis (the pregnancy-associated pustular presentation). L40.2 (acrodermatitis continua of Hallopeau) and L40.3 (pustulosis palmaris et plantaris) are *localized* pustular forms and are **not** the generalized pustular disease; they should not be substituted for L40.1 when the diagnosis is GPP. The arthropathic sub-codes (L40.5x) describe psoriatic arthritis and are unrelated to the cutaneous pustular presentation.

## 3. Common coding pitfalls at prior authorization

- **L40.0 substituted for L40.1.** The most common and most consequential error. Often occurs when a patient carries a longstanding plaque-psoriasis history that is coded by habit, and the newer GPP diagnosis is not reflected. Correct the active diagnosis to L40.1.
- **Unspecified L40.9.** An unspecified psoriasis code does not establish the GPP indication and will not reliably support a GPP-specific coverage determination; specify L40.1.
- **Localized pustular codes (L40.2 / L40.3) used for generalized disease.** These describe distinct localized entities; they will not support a GPP determination.
- **Diagnosis present in narrative but not coded.** A chart note describing a pustular flare is not sufficient if the claim carries a non-GPP code; the coded diagnosis on the claim is what adjudicates.

## 4. Practical guidance for the verification step

At benefits verification and again before PA submission, confirm that:

1. The **active, coded diagnosis is L40.1**.
2. The chart notes describe the generalized pustular presentation consistent with L40.1.
3. Where a patient has both plaque and pustular disease, the diagnosis relevant to the requested GPP therapy — **L40.1** — is the one submitted with the authorization request.

Correct coding is a low-cost, high-yield control: a single-character coding error (L40.0 vs L40.1) is enough to turn a covered request into a denial, and it is entirely preventable at the verification step.
